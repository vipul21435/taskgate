# Greatest common divisors

The file `input/pairs.txt` in the working directory holds one pair of
non-negative integers per line, separated by a single space; no pair is `0 0`.

For each pair, in order, write its greatest common divisor to
`output/gcds.txt`, one per line, as a base-10 integer with no sign and no
leading zeros. End every line, including the last, with a single `\n`. Create
the `output/` directory if it does not exist.
