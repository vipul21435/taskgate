# Integer determinants

The file `input/matrices.txt` in the working directory holds square matrices of
integers. Each row of a matrix is one line of entries separated by single
spaces; matrices are separated by one empty line. Every matrix has between 1
and 8 rows.

For each matrix, in order, write its determinant to `output/determinants.txt`,
one per line: an exact base-10 integer with a leading `-` when negative, no `+`
sign and no leading zeros. End every line, including the last, with a single
`\n`. Create the `output/` directory if it does not exist.
