# Words per line

The file `input/text.txt` in the working directory holds lines of ASCII text.
A word is a maximal run of characters other than spaces.

For each line, in order, write the number of words on it to
`output/counts.txt`, one base-10 count per line (an empty line has 0 words).
End every line, including the last, with a single `\n`. Create the `output/`
directory if it does not exist.
